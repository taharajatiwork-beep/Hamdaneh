# هم‌دانه (Hamdaneh)

یک دفتر مشترک برای دو نفر. هر روز یک سؤال، یک جواب، و یک باغ که با حضور هر دو رشد می‌کند. جواب هر نفر تا وقتی دیگری جواب نداده پنهان می‌ماند.

A shared daily journal for two people. One question a day, one answer each, and a garden that only grows when both show up. Each answer stays hidden until the other has answered.

> وضعیت: نمونه‌ی قابل‌کلیک (prototype). داده‌ها فقط در مرورگر ذخیره می‌شوند و هنوز دو دستگاه به هم وصل نمی‌شوند.

## ایده

«رشته» در فارسی هم یعنی streak و هم یعنی نخ. همین ایده‌ی طراحی است:

- دو شخصیت دانه با یک **نخ قرمز** به هم وصل‌اند. هر روز که هر دو بیایند، دانه‌ها نزدیک‌تر می‌شوند و نخ شل می‌شود.
- نوار روزها همان نخ است و هر روز کامل یک گره.
- سبک بصری **هرباریوم**: برچسب‌های «نمونه»، گیاه خطی، نام لاتین هر مرحله.
- ژورنال یک **دفتر کلاژی** است: هر روز یک صفحه با نوار چسب، پولاروید، یادداشت خط‌دار و برچسب‌های قابل‌جابه‌جایی.

## امکانات و مرحله‌بندی

امکانات یکی‌یکی باز می‌شوند تا کاربر تازه‌وارد فقط یک کار ببیند.

| مرحله | چه چیزی باز می‌شود |
|---|---|
| روز ۱ | فقط سؤال امروز و یک دکمه |
| اولین روز کامل | باغ |
| ۳ روز کامل | ژورنال و عکس |
| ۷ روز کامل | نامه‌های مناسبتی (سالگرد، یلدا، نوروز، کریسمس، ولنتاین، هالووین) |
| ۱۴ روز کامل | صفحه‌ی «ما»: نام، لقب، رنگ و جوانه‌ی دانه‌ها، سالگرد، کلمه‌های رمزی |

نامه‌ها بدون هوش مصنوعی و با قالب‌های هوشمند از جواب‌ها، لقب‌ها و کلمه‌های رمزی خودتان ساخته می‌شوند.

## اجرا

بدون ساخت و وابستگی:

```
index.html          برنامه
style-options.html  مقایسه‌ی چهار سبک بصری که از بینشان هرباریوم انتخاب شد
```

`index.html` را در مرورگر باز کنید. فونت‌ها (Vazirmatn، Amiri، Aref Ruqaa، DM Mono) از Google Fonts لود می‌شوند. اگر آفلاین باشید، فونت‌های جایگزین سیستم استفاده می‌شوند.

در پایین صفحه‌ی «امروز» دو لینک نمایشی هست: «شروع از روز اول» و «داده‌ی نمونه». با دکمه‌های بالای صفحه می‌توانید جای سارا یا آرمان بنشینید.
